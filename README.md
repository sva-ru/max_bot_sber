# Канал «Бизнес-Фактор Юго-Запад» в мессенджере MAX

Проект для автоматизации публикаций в канале, посвящённом клиентам крупного и среднего бизнеса Юго-Западного банка Сбербанка России.

## Возможности
- Автоматическая публикация новостей, кейсов и аналитики.
- Планировщик: каждые N часов + утренний пост в 9:00.
- Ручное управление через команды бота: /publish, /test, /stats.
- Хранение истории публикаций в SQLite.
- Защита от дублей по URL источника.

## Быстрый старт
1. Создайте канал в MAX через @channel_bot.
2. Создайте бота через @masterbot, получите токен.
3. Добавьте бота в администраторы канала.
   4. Скопируйте `.env` в `.env` и заполните:
         - `MAX_BOT_TOKEN` — токен бота.
         - `CHANNEL_CHAT_ID` — ID канала (можно получить, отправив тестовое сообщение и посмотрев лог).
      5. Установите зависимости:
         ```bash
         pip install -r requirements.txt
