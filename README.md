# Канал «Бизнес-Фактор Юго-Запад» в мессенджере MAX

Проект автоматизации публикаций для клиентов крупного и среднего бизнеса
Юго-Западного банка Сбербанка России (Краснодарский край, Ростовская область,
Ставрополье, Крым, республики Северного Кавказа).

## Возможности

- Автопубликация новостей, кейсов и аналитики.
- Планировщик: каждые N часов + утренний пост в 9:00.
- Ручное управление через бота: `/publish`, `/test`, `/stats`, `/help`.
- Генерация текста через GigaChat API.
- Фильтр по дате: только текущий год и текущий квартал.
- Извлечение ИНН и названий компаний из открытых источников.
- Нормализация ссылок (разворот редиректов, удаление UTM, кодирование).
- История публикаций в SQLite.
- Отдельный лог отбраковки RSS (`rss_rejected.log`).

## Быстрый старт

1. Создайте канал в MAX через `@channel_bot`.
2. Создайте бота через `@masterbot`, получите токен.
3. Добавьте бота в администраторы канала.
4. Скопируйте `.env.example` в `.env` и заполните переменные.
5. Установите зависимости: `pip install -r requirements.txt`.
